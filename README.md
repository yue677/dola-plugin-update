## 2026-11-21 工作台 0.2.79 / 插件 0.9.172

- Dola 网页普通 2.0 支持在原对话自动续回。识别对应任务的 Plus 提示后，最多按两条不同提示各补回一次。收到生成回执或成片后停止续回。遇到平台明确提示今日免费额度用尽时，按现有额度规则处理。
- 国际版即梦 Dreamina 全能参考会自动 @ 分镜中手动添加的站位图，并标注「是参考图片，只作为位置参考，根据提示词描述辅助站位进行创作。」参考图总数超过 9 张时提示调整。
- Dola 网页正常退出后可在同一账号恢复仍有效的会话登录。主动退出登录后按退出状态保留。原有网页和桌面客户端导入入口均可继续使用。
- 请在任务完成后更新并重开工作台，再在字字动画更新插件并完全退出重开。

完整说明见 [更新记录](CHANGELOG.md)。

## 插件0.9.141：普通Dola 2.0只上传图片

- 修复普通Dola Seedance 2.0误带角色参考音频：此选项只上传图片，字字中选中的音频会跳过，避免图片/视频上传入口因混入音频而失败。
- 后台固定15秒、原对话单次“继续提交”、回执等待和原分镜回传规则保持；Dola专家四视频、豆包、国内/国际即梦和API等其他模式的音频逻辑不变。
- 已在实际出错分镜验证8张图片全部上传、0音频、完整原提示词及15秒设置，停于发送前；本轮没有新增视频生成。任务结束后更新插件并完全退出重开字字即可，工作台仍为0.2.73，无需再次更新。
