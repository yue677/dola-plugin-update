## 插件0.9.141：普通Dola 2.0只上传图片

- 修复普通Dola Seedance 2.0误带角色参考音频：此选项只上传图片，字字中选中的音频会跳过，避免图片/视频上传入口因混入音频而失败。
- 后台固定15秒、原对话单次“继续提交”、回执等待和原分镜回传规则保持；Dola专家四视频、豆包、国内/国际即梦和API等其他模式的音频逻辑不变。
- 已在实际出错分镜验证8张图片全部上传、0音频、完整原提示词及15秒设置，停于发送前；本轮没有新增视频生成。任务结束后更新插件并完全退出重开字字即可，工作台仍为0.2.73，无需再次更新。
